# Hello
最近在开发一款外语学习的 App，我给它起名叫做 FmS。理论上是支持所有外语的，反正我是用来学习英语和德语的。

一个月前，写了第一篇文章，想要介绍给别人。但不好意思分享给朋友们，因为还有很多问题，估计大家都不知道怎么用。经过一个月的辛苦修改，至少我觉得，可以正式跟大家见个面了。

提示：现在仍然不是正式版本，还有不少问题，但想要体验一下，已经可以了。

# 功能

直接上干货，这个 App 包含哪些功能：

1，听写。将任何音频转为逐句听写的材料，比如一本有声书。通过 AI 模型将音频识别为字幕，针对每一条字幕进行听写。至于听写的方式，可以用传统的纸和笔进行，可以键盘打字，可以语音输入。

2，阅读。将一本书一句一句地录入，然后对每一段，每一章节，可以调用 AI 进行解释，用简单的语言转写，做总结，甚至用 AI 生成小测试，类似阅读理解。还可以做笔记，并交给 AI 评价是否正确。

3，朗读。将课文，甚至一本电子书，直接转换成小段的朗读材料，如果有音频，可以导入，如果没有，可以 AI 生成。朗读录音之后，会进行语音识别，计算准确率，流畅度，发音标准度。还可以让 AI 分析问题所在，给出练习和提高的建议。

4，记忆卡片。将问题和答案分门别类制作成卡片，可以复习，会根据遗忘曲线算法指定复习计划。

5，笔记整理。使用 Markdown 格式记笔记，自动转为网页格式浏览，支持全文搜索。

6，各种小工具。设备间文件互传，OCR 图片文本识别，是我最喜欢用的工具。

提示：前 Windows 电脑和 Android 手机是体验最好的，因为边开发边测试。至于苹果系列产品，因为我没有苹果设备，所以虽然有安装包，但是使用体验还不知道。而且，Android 手机是要依赖 Windows 电脑使用的，单纯的 Android 手机导入数据比较难。

# 特色
最大的特色就是高度的 AI 集成，而且免费。App 中使用的所有 AI 模型，都是开源免费的。这就意味着，可以享受最新的 AI 发展成果，但并不需要付费。

另一个突出的特色是 Agent 集成。不论国外的 Claude Code, Codex, Opencode 还是国内的 WorkBuddy, 千问办公，都能支持。你可以通过 Agent 操作 App 里的任何页面和功能。

因为我最开始的开发原则就是，user-friendly 和 agent-friendly 并重。可以通过 Agent 跳转页面，可以通过 Agent 读取，处理，写入数据。这也是为什么能够使用 Agent 将电子书制作成学习数据的原因，只需告诉 Agent 一句话，剩下的他都能自动完成。

# 设计
因为不论电子书，有声书，还是音频资料，大都是有版权保护的。你可以自己使用，但分享给别人就有违法嫌疑。

所以，用户应当维护自己的学习资料，我只是提供了整理和使用这些资料的工具。因此在设计上，用户必须首先在电脑（称为 Hub）上安装，整理好所有的数据。然后可以把部分数据同步到其他电脑或手机（称为 Follower）上，使用这些数据。

因此，虽然有网站，用于用户注册和登录，可以分享数据，可以上传私有数据在网站上练习。但是网站并不会提供有版权保护的学习资料给新用户下载。

另一方面，我认为，使用 AI 和 Agent 将会成为每个人最基本的能力，借助这种能力，制作自己的学习资料也并不困难。

# 感慨
再好的工具，没人用，有什么意义呢？

我最怀念的，是两年前使用最初级的版本仍然认认真真学习的自己。工具并不算好，但我认认真真在用，所以发挥了很大的价值。

后来，不断的升级，不断地设计新版本，界面越来越漂亮，功能越来越花哨，而我用的却越来越少，又真正帮到我多少呢？

我问 AI，它怎么看待我这个 App。它反问我，你的目标用户是谁，你的产品跟其他产品的优势是什么，为什么别人要使用你的产品。

说实话，我不知道该怎么回答。我的目标用户，其实只有我自己，我想开发一款我自己喜欢用的软件。我有自己的偏好，有自己的奇思妙想，我会不断问自己，我想要什么功能，我想要怎样整理自己的资料，我想要通过什么方式学习。

我想，我自己觉得好的东西，也许也能帮助到别人，而且也希望找到更多的伙伴，可以和我使用相同的工具，大家互相分享数据，互相鼓励，共同进步。
