因为使用本地 AI 模型的原因，
该 App 在设计上，是不太传统的。
一个核心问题，
如何在手机上利用电脑的性能？

# Hub
需要一台个人电脑，作为 Hub。Hub 的作用：

1，存储所有的数据。
1.1，数据量大。对于有大量学习资料的用户来说，手机存储完全不够。
1.2，永久存储。因为手机的设计，很多数据一旦卸载应用就被清空了，数据会永久丢失。
1.3，权限问题。手机数据在默认的存储空间里，作为普通用户根本没权限去访问，手机系统就不给你权限。

2，支持 Agent。
在电脑上，可以安装 Agent 用于批量处理数据。目前还没有哪个 Agent 可以装在手机上吧？

3，性能和算力。
手机上不会有显卡，AI 模型对性能和内存要求都很高。

# Follower
手机 App 只是作为电脑的延伸。

有了手机，就不必一定要坐在电脑桌前了。你可以到处走动，可以去散步，可以躺床上，只要带着手机就能用。

手机上只需要从 Hub 下载部分数据，有更改了再同步到 Hub 上。

经过测试，一段278秒的录音，电脑上处理需要181秒，手机上需要396秒。这还是手机使用简化模型的情况，否则手机会更慢。

但是只要手机和电脑连着同一个 WIFI，就可以在手机上直接调用电脑进行数据处理，只需等着处理结果就行了。

# 多 Follower 支持
如果有两台电脑，一个台式机，一个笔记本，同样可以把笔记本作为 Follower。

如果你想把自己的数据分享给别人，拿U盘直接拷贝数据集就行了。没有U盘，只要你们两台电脑连着同一个 WIFI，而你的电脑切换到 Hub 模式，对方切换到 Follower 模式，就能直接连上下载数据。

哪怕不是学习数据。借助 Hub-Follower 之间的跨设备聊天功能，可以直接互相发送消息和文件。不会经过互联网，不会泄露隐私。

# 个人文档 Wiki
电脑上可以直接使用 Markdown 做笔记。然后就可以在电脑上转换成 HTML 网页格式浏览，还可以方便地全文搜索。

在手机上，是有一个在线浏览功能的，只要连接同一个 WIFI，就可以在手机上浏览电脑上的文档。无需下载。

而且无需上传到互联网，一切都在本地，都在自己的掌控之中。

# 总结
我的设计目标，就是将所有的个人设备都连接起来，而不需要插数据线拷贝。

不仅仅数据共享，而且性能和算力也要共享。
