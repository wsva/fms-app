# FmS User Manual

FmS is a language‑learning workspace built around **datasets** — collections of authentic audio, text, and vocabulary that you practice with through dictation, reading, reading aloud, and flashcards. It runs as a **desktop app** (Windows, Linux), an **Android app**, and a **website**, and keeps all of them in sync so your material and your progress follow you between devices.

This manual is written for learners. It walks you from a fresh install to everyday practice, and explains how the app and the website fit together.

## How to read this manual

- New to FmS? Start with [Overview](overview.md), then [Getting Started](getting_started.md).
- Already set up and looking for one feature? Jump straight to the page below.
- Working across a phone and a computer? Read [Multiple Devices, Hub & Sync](multiple_devices.md).
